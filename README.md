# Phonebook

Turborepo monorepo with a React frontend and a Node.js API.

## Apps and packages

- `apps/web` — Vite + React + TypeScript UI
- `apps/api` — Express + TypeScript API
- `packages/shared` — shared contact types and API routes

## Scripts

```bash
npm install
npm run dev
```

- Web: http://localhost:5173
- API: http://localhost:3001/api/health

Other commands:

```bash
npm run build
npm run typecheck
```
